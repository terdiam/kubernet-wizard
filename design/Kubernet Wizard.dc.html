Control-plane endpoint #
Every cluster needs one stable address that clients and nodes use to reach the API server. Set it up even with a single control plane so you can upgrade to HA later without re-issuing certificates.
DNS name (no VIP) #
Point an A record at your control-plane IPs. Works on cloud and baremetal, and needs no L2 adjacency.
endpoint:
  mode: dns
  host: k8s.home.lab
  port: 6443
